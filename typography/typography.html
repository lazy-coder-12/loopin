📐 4pt Sub-grid Layout Logic Line-heights are strictly multiples of 4. Spacing and padding stay on 8 while typography sits perfectly on 4.

Button vs. Label Divergence

Currently matching values by design, kept as separate named styles so button text can diverge later (e.g., all-caps variants or distinct letter-spacing) without requiring structural renames.

Amount (Body) Weight Decision

The only body-level style set to Medium weight instead of Regular. Deliberate choice: subscription costs are the core data point users check, deserving visual weight without escalating to a heading tier.

Strict System Restraint (12 Styles)

Every style corresponds directly to a recurring UI moment. Avoids arbitrary sizes (like 15sp) that bloat design systems without serving a distinct functional role.
